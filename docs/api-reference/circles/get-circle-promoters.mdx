Use this endpoint to list all promoters that currently belong to a specific circle within a program. The response is paginated and supports a free-text search query to filter results. This is useful for auditing circle membership and verifying that commission rules are applied to the correct group of promoters.

## Method and Path

```bash
GET /api/programs/:program_id/circles/:circle_id/promoters
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it in every request as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program the circle belongs to.
</ParamField>

<ParamField path="circle_id" type="string (uuid)" required>
  Unique identifier of the circle whose promoters you want to retrieve.
</ParamField>

### Query Parameters

<ParamField query="query" type="string">
  Free-text search string to filter promoters by name or other identifier fields.
</ParamField>

<ParamField query="skip" type="number">
  Number of records to skip for pagination. Defaults to `0`.
</ParamField>

<ParamField query="take" type="number">
  Maximum number of records to return per page. Defaults to `10`.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched promoters of circle."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="data" type="array">
      Array of promoter objects belonging to the circle.
      <Expandable title="promoter">
        <ResponseField name="promoter_id" type="string (uuid)">
          Unique identifier of the promoter.
        </ResponseField>
        <ResponseField name="name" type="string">
          Display name of the promoter.
        </ResponseField>
        <ResponseField name="status" type="string">
          Current status of the promoter. One of `active` | `archived`.
        </ResponseField>
        <ResponseField name="created_at" type="string (ISO 8601)">
          Timestamp when the promoter was created.
        </ResponseField>
        <ResponseField name="updated_at" type="string (ISO 8601)">
          Timestamp when the promoter record was last updated.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="count" type="number">
      Total number of promoters in the circle matching the query.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET "https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/circles/c1d2e3f4-0000-0000-0000-000000000002/promoters?skip=0&take=10" \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Promoters retrieved successfully. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated caller lacks read access to this circle. |
| `404 Not Found` | No circle exists with the provided `circle_id` in this program. |
