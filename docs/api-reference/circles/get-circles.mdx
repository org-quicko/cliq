Use this endpoint to retrieve all circles that exist within a program. The response is paginated and can be filtered by circle name. Circles represent promoter segments and are used alongside commission functions to determine which payout rules apply to which group of promoters.

## Method and Path

```bash
GET /api/programs/:program_id/circles
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it in every request as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program whose circles you want to retrieve.
</ParamField>

### Query Parameters

<ParamField query="name" type="string">
  Filter results by circle name. Returns circles whose name contains the provided string (case-insensitive).
</ParamField>

<ParamField query="skip" type="number">
  Number of records to skip for pagination. Defaults to `0`.
</ParamField>

<ParamField query="take" type="number">
  Maximum number of records to return. Defaults to `10`.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched all circles."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="data" type="array">
      Array of circle objects.
      <Expandable title="circle">
        <ResponseField name="circle_id" type="string (uuid)">
          Unique identifier for the circle.
        </ResponseField>
        <ResponseField name="name" type="string">
          Display name of the circle.
        </ResponseField>
        <ResponseField name="is_default_circle" type="boolean">
          Whether this circle is the default circle for the program.
        </ResponseField>
        <ResponseField name="created_at" type="string (ISO 8601)">
          Timestamp when the circle was created.
        </ResponseField>
        <ResponseField name="updated_at" type="string (ISO 8601)">
          Timestamp when the circle was last updated.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="count" type="number">
      Total number of circles matching the query.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET "https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/circles?skip=0&take=10" \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Circles retrieved successfully. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated caller lacks read access to this program's circles. |
