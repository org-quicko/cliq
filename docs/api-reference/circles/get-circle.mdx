Use this endpoint to retrieve the details of a specific circle within a program. You can use the returned data to inspect circle metadata, verify its name, and confirm whether it is the default circle before performing updates or promoter assignments.

## Method and Path

```bash
GET /api/programs/:program_id/circles/:circle_id
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it in every request as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program the circle belongs to.
</ParamField>

<ParamField path="circle_id" type="string (uuid)" required>
  Unique identifier of the circle to retrieve.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched circle."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="circle_id" type="string (uuid)">
      Unique identifier for the circle.
    </ResponseField>
    <ResponseField name="name" type="string">
      Display name of the circle.
    </ResponseField>
    <ResponseField name="is_default_circle" type="boolean">
      Whether this circle is the default circle for the program.
    </ResponseField>
    <ResponseField name="created_at" type="string (ISO 8601)">
      Timestamp when the circle was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string (ISO 8601)">
      Timestamp when the circle was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/circles/c1d2e3f4-0000-0000-0000-000000000002 \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Circle details retrieved successfully. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated caller lacks read access to this circle. |
| `404 Not Found` | No circle exists with the provided `circle_id` in this program. |
