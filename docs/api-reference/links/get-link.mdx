Use this endpoint to retrieve the details of a specific referral link belonging to a promoter within a program. This is useful for verifying the `ref_val` referral code, checking the link's current status, and confirming its metadata before referencing it in conversion events or downstream workflows.

## Method and Path

```bash
GET /api/programs/:program_id/promoters/:promoter_id/links/:link_id
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it in every request as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program the promoter belongs to.
</ParamField>

<ParamField path="promoter_id" type="string (uuid)" required>
  Unique identifier of the promoter who owns the link.
</ParamField>

<ParamField path="link_id" type="string (uuid)" required>
  Unique identifier of the referral link to retrieve.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched link {link_id}."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="link_id" type="string (uuid)">
      Unique identifier of the link.
    </ResponseField>
    <ResponseField name="name" type="string">
      Display name of the link.
    </ResponseField>
    <ResponseField name="ref_val" type="string">
      The referral code used to attribute conversions to this link. Pass this value to `POST /api/signups` or `POST /api/purchases` to record a conversion.
    </ResponseField>
    <ResponseField name="status" type="string">
      Current status of the link. One of `active` | `archived`.
    </ResponseField>
    <ResponseField name="created_at" type="string (ISO 8601)">
      Timestamp when the link was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string (ISO 8601)">
      Timestamp when the link was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/promoters/p1a2b3c4-0000-0000-0000-000000000010/links/l1f2e3d4-0000-0000-0000-000000000020 \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Link details retrieved successfully. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated caller lacks read access to this promoter's links. |
| `404 Not Found` | No link exists with the provided `link_id` for this promoter and program. |
