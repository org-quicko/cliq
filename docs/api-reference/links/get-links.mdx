Use this endpoint to retrieve all referral links that belong to a specific promoter within a program. The response is paginated and can be filtered by link name. Use this to inspect which referral codes a promoter has active, track link-level performance, or audit link statuses before processing conversions.

## Method and Path

```bash
GET /api/programs/:program_id/promoters/:promoter_id/links
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it in every request as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program the promoter belongs to.
</ParamField>

<ParamField path="promoter_id" type="string (uuid)" required>
  Unique identifier of the promoter whose links you want to retrieve.
</ParamField>

### Query Parameters

<ParamField query="name" type="string">
  Filter results by link name. Returns links whose name contains the provided string (case-insensitive).
</ParamField>

<ParamField query="skip" type="number">
  Number of records to skip for pagination. Defaults to `0`.
</ParamField>

<ParamField query="take" type="number">
  Maximum number of records to return per page. Defaults to `10`.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched all links."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="data" type="array">
      Array of link objects.
      <Expandable title="link">
        <ResponseField name="link_id" type="string (uuid)">
          Unique identifier of the link.
        </ResponseField>
        <ResponseField name="name" type="string">
          Display name of the link.
        </ResponseField>
        <ResponseField name="ref_val" type="string">
          The referral code used to attribute conversions to this link.
        </ResponseField>
        <ResponseField name="status" type="string">
          Current status of the link. One of `active` | `archived`.
        </ResponseField>
        <ResponseField name="created_at" type="string (ISO 8601)">
          Timestamp when the link was created.
        </ResponseField>
        <ResponseField name="updated_at" type="string (ISO 8601)">
          Timestamp when the link was last updated.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="count" type="number">
      Total number of links matching the query.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET "https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/promoters/p1a2b3c4-0000-0000-0000-000000000010/links?skip=0&take=10" \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Links retrieved successfully. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated caller lacks read access to this promoter's links. |
| `404 Not Found` | The specified program or promoter does not exist. |
