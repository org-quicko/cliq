---
title: "Get Promoter of Member — Find a Member's Promoter"
sidebarTitle: "Member Promoter"
description: "Retrieve the promoter organization that a specific member belongs to within a Cliq program. Each member is associated with exactly one promoter per program."
---

The Get Promoter of Member endpoint returns the promoter that a given member is associated with inside a specific program. Since a member can only belong to one promoter per program, this endpoint always returns a single promoter object. This is useful for member-facing views where you need to display the team or organization context for the currently authenticated member.

## Endpoint

```bash
GET /api/programs/:program_id/members/:member_id/promoter
```

## Authentication

<Warning>
  This endpoint requires authentication. Include a valid Bearer token in the `Authorization` header.
</Warning>

## Path Parameters

<ParamField path="program_id" type="string (UUID)" required>
  The unique identifier of the program in which to look up the member's promoter.
</ParamField>

<ParamField path="member_id" type="string (UUID)" required>
  The unique identifier of the member whose promoter should be retrieved.
</ParamField>

## Response

<ResponseField name="message" type="string">
  A human-readable confirmation message. Example: `"Successfully fetched promoter of Member mem-9abc-def0-1234-5678."`
</ResponseField>

<ResponseField name="result" type="object">
  The promoter object associated with the member.

  <Expandable title="result fields">
    <ResponseField name="promoter_id" type="string (UUID)">
      The unique identifier of the promoter.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name of the promoter organization.
    </ResponseField>
    <ResponseField name="status" type="string">
      The promoter's current status. One of: `active`, `inactive`.
    </ResponseField>
    <ResponseField name="created_at" type="string (ISO 8601)">
      Timestamp when the promoter was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string (ISO 8601)">
      Timestamp when the promoter was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example Request

```bash
curl -X GET https://your-cliq-instance.com/api/programs/prog-1234-abcd-5678-efgh/members/mem-9abc-def0-1234-5678/promoter \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

## Example Response

```json
{
  "message": "Successfully fetched promoter of Member mem-9abc-def0-1234-5678.",
  "result": {
    "promoter_id": "prom-aaaa-bbbb-cccc-dddd",
    "name": "Acme Affiliates",
    "status": "active",
    "created_at": "2024-01-20T09:00:00.000Z",
    "updated_at": "2024-01-20T09:00:00.000Z"
  }
}
```

## Status Codes

| Status Code | Description                                                       |
|-------------|-------------------------------------------------------------------|
| `200`       | OK — promoter data returned successfully.                         |
| `401`       | Unauthorized — missing or invalid Bearer token.                   |
| `403`       | Forbidden — caller does not have permission to access this data.  |
| `404`       | Not Found — the member does not belong to any promoter in this program. |
