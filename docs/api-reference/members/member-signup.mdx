The Member Sign Up endpoint registers a new member into a specific affiliate program. Members are distinct from admin users — they access the program exclusively through the promoter portal and belong to a promoter's team. This endpoint is public and does not require authentication, making it suitable for embedding in affiliate onboarding flows.

## Endpoint

```bash
POST /api/programs/:program_id/members/signup
```

## Authentication

<Note>
  This endpoint is **public**. No authentication token is required.
</Note>

## Path Parameters

<ParamField path="program_id" type="string (UUID)" required>
  The unique identifier of the program the new member is joining.
</ParamField>

## Request Body

<ParamField body="email" type="string" required>
  The email address for the new member account. Must be unique within the program.
</ParamField>

<ParamField body="password" type="string">
  The password for the new member account.
</ParamField>

<ParamField body="first_name" type="string" required>
  The member's first name.
</ParamField>

<ParamField body="last_name" type="string" required>
  The member's last name.
</ParamField>

## Response

<ResponseField name="message" type="string">
  A human-readable confirmation message. Example: `"Successfully signed up member."`
</ResponseField>

<ResponseField name="result" type="object">
  The newly created member object.

  <Expandable title="result fields">
    <ResponseField name="member_id" type="string (UUID)">
      The unique identifier of the created member.
    </ResponseField>
    <ResponseField name="email" type="string">
      The member's email address.
    </ResponseField>
    <ResponseField name="first_name" type="string">
      The member's first name.
    </ResponseField>
    <ResponseField name="last_name" type="string">
      The member's last name.
    </ResponseField>
    <ResponseField name="created_at" type="string (ISO 8601)">
      Timestamp when the member was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string (ISO 8601)">
      Timestamp when the member was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example Request

```bash
curl -X POST https://your-cliq-instance.com/api/programs/prog-1234-abcd-5678-efgh/members/signup \
  -H "Content-Type: application/json" \
  -d '{
    "email": "alice.johnson@example.com",
    "password": "MemberPass@456",
    "first_name": "Alice",
    "last_name": "Johnson"
  }'
```

## Example Response

```json
{
  "message": "Successfully signed up member.",
  "result": {
    "member_id": "mem-9abc-def0-1234-5678",
    "email": "alice.johnson@example.com",
    "first_name": "Alice",
    "last_name": "Johnson",
    "created_at": "2024-02-01T12:00:00.000Z",
    "updated_at": "2024-02-01T12:00:00.000Z"
  }
}
```

## Status Codes

| Status Code | Description                                                    |
|-------------|----------------------------------------------------------------|
| `201`       | Created — the member account was successfully created.         |
| `400`       | Bad Request — missing or invalid fields in the body.           |
| `404`       | Not Found — the specified `program_id` does not exist.         |
| `409`       | Conflict — a member with that email already exists in the program. |
