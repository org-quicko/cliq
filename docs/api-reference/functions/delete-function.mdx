Permanently removes a function from the program. Once deleted, the function will no longer fire on new trigger events. Commissions and circle changes that were already applied by this function are not reversed. Consider setting the function's `status` to `inactive` if you want to temporarily disable it without losing its configuration.

<Warning>
  This action is **irreversible**. The function and all its configuration will be permanently deleted. If you only want to pause the function, use the [Update Function](/api-reference/functions/update-function) endpoint to set `status` to `inactive` instead.
</Warning>

## Endpoint

```text
DELETE /api/programs/:program_id/functions/:function_id
```

## Authentication

All requests require a Bearer token in the `Authorization` header.

```text
Authorization: Bearer <your_token>
```

## Path Parameters

<ParamField path="program_id" type="string" required>
  The UUID of the program the function belongs to.
</ParamField>

<ParamField path="function_id" type="string" required>
  The UUID of the function to delete.
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation message — `"Successfully deleted function."`
</ResponseField>

## Example

```bash
curl -X DELETE https://your-cliq-instance.com/api/programs/prog_abc123/functions/fn_uuid_here \
  -H "Authorization: Bearer <your_token>"
```

### Example Response

```json
{
  "message": "Successfully deleted function."
}
```

## Status Codes

| Status | Description |
|--------|-------------|
| `200 OK` | Function deleted successfully. |
| `401 Unauthorized` | Missing or invalid Bearer token. |
| `403 Forbidden` | Token does not have permission to delete this function. |
| `404 Not Found` | No function found with the given ID in this program. |
