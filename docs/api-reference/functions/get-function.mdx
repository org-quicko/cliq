Retrieve the full details of a specific function, including its trigger, effect type, effect configuration, any attached conditions, and the circle it is scoped to. Use this when you need to inspect or display a particular commission rule.

## Endpoint

```text
GET /api/programs/:program_id/functions/:function_id
```

## Authentication

All requests require a Bearer token in the `Authorization` header.

```text
Authorization: Bearer <your_token>
```

## Path Parameters

<ParamField path="program_id" type="string" required>
  The UUID of the program the function belongs to.
</ParamField>

<ParamField path="function_id" type="string" required>
  The UUID of the function to retrieve.
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation message — `"Successfully fetched function."`
</ResponseField>

<ResponseField name="result" type="object">
  The function object.

  <Expandable title="result fields">
    <ResponseField name="function_id" type="string">
      UUID of the function.
    </ResponseField>
    <ResponseField name="name" type="string">
      Human-readable name of the function.
    </ResponseField>
    <ResponseField name="trigger" type="string">
      The event that triggers this function: `signup` or `purchase`.
    </ResponseField>
    <ResponseField name="effect_type" type="string">
      The type of effect applied: `generate_commission` or `switch_circle`.
    </ResponseField>
    <ResponseField name="status" type="string">
      Current status: `active` or `inactive`.
    </ResponseField>
    <ResponseField name="effect" type="object">
      Effect configuration.

      <Expandable title="generate_commission effect shape">
        <ResponseField name="effect.commission.commission_type" type="string">
          `fixed` or `percentage`.
        </ResponseField>
        <ResponseField name="effect.commission.commission_value" type="number">
          The commission amount or percentage.
        </ResponseField>
      </Expandable>

      <Expandable title="switch_circle effect shape">
        <ResponseField name="effect.target_circle_id" type="string">
          UUID of the target circle.
        </ResponseField>
        <ResponseField name="effect.target_circle_name" type="string">
          Display name of the target circle, if set.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="conditions" type="array">
      Condition objects attached to this function.
    </ResponseField>
    <ResponseField name="circle_id" type="string">
      UUID of the circle this function is scoped to.
    </ResponseField>
    <ResponseField name="circle_name" type="string">
      Display name of the circle.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 creation timestamp.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      ISO 8601 last-updated timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET https://your-cliq-instance.com/api/programs/prog_abc123/functions/fn_uuid_here \
  -H "Authorization: Bearer <your_token>"
```

## Status Codes

| Status | Description |
|--------|-------------|
| `200 OK` | Function returned successfully. |
| `401 Unauthorized` | Missing or invalid Bearer token. |
| `403 Forbidden` | Token does not have permission to read this function. |
| `404 Not Found` | No function found with the given ID in this program. |
