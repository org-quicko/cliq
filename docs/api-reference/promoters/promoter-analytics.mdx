Use this endpoint to retrieve aggregated analytics for all promoters within a program, ranked by performance metrics such as signup commissions, purchase commissions, number of signups, or total revenue. Results are paginated and support flexible date range filtering using either a preset period or explicit start and end dates.

## Method and Path

```http
GET /api/programs/:program_id/analytics/promoters
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program for which promoter analytics are being retrieved.
</ParamField>

### Query Parameters

<ParamField query="sortBy" type="string">
  Metric to rank promoters by. Accepted values:

  - `signup_commission` — Total commission earned from signup conversions.
  - `purchase_commission` — Total commission earned from purchase conversions.
  - `signups` — Total number of referred signups.
  - `revenue` — Total revenue attributed to the promoter.

  Defaults to `signup_commission`.
</ParamField>

<ParamField query="period" type="string">
  Preset time window for analytics. Defaults to `30days`. Examples: `7days`, `30days`, `90days`.
</ParamField>

<ParamField query="startDate" type="string (ISO 8601)">
  Start of a custom date range. Use together with `endDate` to override the `period` preset.
</ParamField>

<ParamField query="endDate" type="string (ISO 8601)">
  End of a custom date range. Use together with `startDate` to override the `period` preset.
</ParamField>

<ParamField query="skip" type="number">
  Number of records to skip for pagination. Defaults to `0`.
</ParamField>

<ParamField query="take" type="number">
  Maximum number of records to return. Defaults to `5`.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched promoters sorted by {sortBy}."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="data" type="array">
      Array of promoter analytics records sorted by the requested metric.
      <Expandable title="promoter analytics entry">
        <ResponseField name="promoter_id" type="string (uuid)">
          Unique identifier for the promoter.
        </ResponseField>
        <ResponseField name="name" type="string">
          Display name of the promoter.
        </ResponseField>
        <ResponseField name="signup_commission" type="number">
          Total commission earned from signup conversions in the given period.
        </ResponseField>
        <ResponseField name="purchase_commission" type="number">
          Total commission earned from purchase conversions in the given period.
        </ResponseField>
        <ResponseField name="signups" type="number">
          Total number of referred signups in the given period.
        </ResponseField>
        <ResponseField name="revenue" type="number">
          Total revenue attributed to the promoter in the given period.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="count" type="number">
      Total number of promoter analytics records matching the query.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET "https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/analytics/promoters?sortBy=purchase_commission&period=30days&skip=0&take=5" \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Analytics retrieved successfully. |
| `400 Bad Request` | Invalid query parameters or date range format. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated member lacks access to analytics for this program. |
