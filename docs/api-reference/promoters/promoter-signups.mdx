Use this endpoint to fetch all signup conversion events that were referred by a specific promoter within a program. Each record represents a contact who signed up through the promoter's referral link. This data is useful for auditing referral activity and calculating signup-based commissions.

## Method and Path

```http
GET /api/programs/:program_id/promoters/:promoter_id/signups
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program.
</ParamField>

<ParamField path="promoter_id" type="string (uuid)" required>
  Unique identifier of the promoter whose signups are being retrieved.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched all signups of promoter."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="data" type="array">
      Array of signup records attributed to the promoter.
      <Expandable title="signup">
        <ResponseField name="signup_id" type="string (uuid)">
          Unique identifier for the signup event.
        </ResponseField>
        <ResponseField name="contact_id" type="string (uuid)">
          Identifier of the contact who signed up.
        </ResponseField>
        <ResponseField name="promoter_id" type="string (uuid)">
          Promoter who referred this signup.
        </ResponseField>
        <ResponseField name="program_id" type="string (uuid)">
          Program this signup belongs to.
        </ResponseField>
        <ResponseField name="created_at" type="string (ISO 8601)">
          Timestamp when the signup was recorded.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="count" type="number">
      Total number of signups attributed to the promoter.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET "https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/promoters/p5e6f7g8-0000-0000-0000-000000000002/signups" \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Signups retrieved successfully. |
| `400 Bad Request` | Invalid path or query parameters. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated member lacks access to this promoter's signups. |
| `404 Not Found` | Promoter or program not found. |
