Use this endpoint to retrieve a paginated list of commissions earned by a specific promoter within a program. You can filter by conversion type (signup or purchase), specific referral link, or contact, and sort by creation or update time. This is the primary endpoint for building commission ledgers and payout views.

## Method and Path

```http
GET /api/programs/:program_id/promoters/:promoter_id/commissions
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program.
</ParamField>

<ParamField path="promoter_id" type="string (uuid)" required>
  Unique identifier of the promoter whose commissions are being listed.
</ParamField>

### Query Parameters

<ParamField query="conversion_type" type="string">
  Filter by the type of conversion that generated the commission. Accepted values: `signup` | `purchase`.
</ParamField>

<ParamField query="link_id" type="string">
  Filter commissions to those generated through a specific referral link ID.
</ParamField>

<ParamField query="contact_id" type="string">
  Filter commissions to those generated by a specific referred contact ID.
</ParamField>

<ParamField query="sort_by" type="string">
  Field to sort commissions by. Accepted values:

  - `updatedAt` — Sort by the time the commission was last updated. *(default)*
  - `createdAt` — Sort by the time the commission was created.
</ParamField>

<ParamField query="sort_order" type="string">
  Sort direction. Accepted values: `ASC` | `DESC`. Defaults to `DESC` (newest first).
</ParamField>

<ParamField query="skip" type="number">
  Number of records to skip for pagination. Defaults to `0`.
</ParamField>

<ParamField query="take" type="number">
  Maximum number of records to return per page. Defaults to `10`.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched all commissions of promoter."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="data" type="array">
      Array of commission records.
      <Expandable title="commission">
        <ResponseField name="commission_id" type="string (uuid)">
          Unique identifier for the commission record.
        </ResponseField>
        <ResponseField name="promoter_id" type="string (uuid)">
          Promoter who earned this commission.
        </ResponseField>
        <ResponseField name="program_id" type="string (uuid)">
          Program this commission belongs to.
        </ResponseField>
        <ResponseField name="conversion_type" type="string">
          Type of conversion: `signup` | `purchase`.
        </ResponseField>
        <ResponseField name="amount" type="number">
          Commission amount earned.
        </ResponseField>
        <ResponseField name="link_id" type="string (uuid)">
          Referral link through which the commission was generated, if applicable.
        </ResponseField>
        <ResponseField name="contact_id" type="string (uuid)">
          Contact whose action triggered this commission.
        </ResponseField>
        <ResponseField name="created_at" type="string (ISO 8601)">
          Timestamp when the commission was created.
        </ResponseField>
        <ResponseField name="updated_at" type="string (ISO 8601)">
          Timestamp when the commission was last updated.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="count" type="number">
      Total number of commission records matching the query filters.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET "https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/promoters/p5e6f7g8-0000-0000-0000-000000000002/commissions?conversion_type=purchase&sort_by=updatedAt&sort_order=DESC&skip=0&take=10" \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Commissions retrieved successfully. |
| `400 Bad Request` | Invalid query parameter values or format. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated member lacks access to this promoter's commissions. |
| `404 Not Found` | Promoter or program not found. |
