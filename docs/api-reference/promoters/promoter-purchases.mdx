Use this endpoint to fetch all purchase conversion events attributed to a specific promoter within a program. Each record represents a transaction made by a contact who was referred by the promoter. You can optionally filter by a specific catalog item using the `item_id` query parameter.

## Method and Path

```http
GET /api/programs/:program_id/promoters/:promoter_id/purchases
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program.
</ParamField>

<ParamField path="promoter_id" type="string (uuid)" required>
  Unique identifier of the promoter whose purchases are being retrieved.
</ParamField>

### Query Parameters

<ParamField query="item_id" type="string">
  Filter purchases by a specific catalog item ID. When provided, only purchases of that item are returned.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched all purchases of promoter."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="data" type="array">
      Array of purchase records attributed to the promoter.
      <Expandable title="purchase">
        <ResponseField name="purchase_id" type="string (uuid)">
          Unique identifier for the purchase event.
        </ResponseField>
        <ResponseField name="contact_id" type="string (uuid)">
          Identifier of the contact who made the purchase.
        </ResponseField>
        <ResponseField name="promoter_id" type="string (uuid)">
          Promoter who referred this purchase.
        </ResponseField>
        <ResponseField name="item_id" type="string">
          Catalog item associated with the purchase, if applicable.
        </ResponseField>
        <ResponseField name="amount" type="number">
          Purchase amount used for commission calculation.
        </ResponseField>
        <ResponseField name="program_id" type="string (uuid)">
          Program this purchase belongs to.
        </ResponseField>
        <ResponseField name="created_at" type="string (ISO 8601)">
          Timestamp when the purchase was recorded.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="count" type="number">
      Total number of purchases attributed to the promoter.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET "https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/promoters/p5e6f7g8-0000-0000-0000-000000000002/purchases" \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Purchases retrieved successfully. |
| `400 Bad Request` | Invalid path or query parameters. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated member lacks access to this promoter's purchases. |
| `404 Not Found` | Promoter or program not found. |
