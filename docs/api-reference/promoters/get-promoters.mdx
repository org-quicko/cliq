Use this endpoint to fetch a paginated list of all promoters registered within a specific program. You can filter results by name and control sort order and pagination through query parameters. This is useful for building admin dashboards and promoter management tables.

## Method and Path

```http
GET /api/programs/:program_id/promoters
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program whose promoters are being listed.
</ParamField>

### Query Parameters

<ParamField query="name" type="string">
  Filter promoters by name. Performs a partial (case-insensitive) match against the promoter's `name` field.
</ParamField>

<ParamField query="skip" type="number">
  Number of records to skip for pagination. Defaults to `0`.
</ParamField>

<ParamField query="take" type="number">
  Maximum number of records to return per page. Defaults to `5`.
</ParamField>

<ParamField query="order" type="string">
  Sort direction for the results. Accepted values: `ASC` | `DESC`. Defaults to `ASC`.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched all promoters of program."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="data" type="array">
      Array of promoter objects.
      <Expandable title="promoter">
        <ResponseField name="promoter_id" type="string (uuid)">
          Unique identifier for the promoter.
        </ResponseField>
        <ResponseField name="name" type="string">
          Display name of the promoter.
        </ResponseField>
        <ResponseField name="logo_url" type="string">
          URL of the promoter's logo, if set.
        </ResponseField>
        <ResponseField name="status" type="string">
          Current status of the promoter: `active` | `archived`.
        </ResponseField>
        <ResponseField name="accepted_terms_and_conditions" type="boolean">
          Whether the promoter has accepted the program's terms and conditions.
        </ResponseField>
        <ResponseField name="admin_member_email" type="string">
          Email of the promoter's admin member, if available.
        </ResponseField>
        <ResponseField name="created_at" type="string (ISO 8601)">
          Timestamp when the promoter was created.
        </ResponseField>
        <ResponseField name="updated_at" type="string (ISO 8601)">
          Timestamp when the promoter was last updated.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="count" type="number">
      Total number of promoters matching the query (before pagination).
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET "https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/promoters?name=jane&skip=0&take=5&order=ASC" \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Promoters listed successfully. |
| `400 Bad Request` | Invalid query parameters. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated member lacks read access to this program's promoters. |
