Use this endpoint to retrieve the complete details of a single promoter identified by their UUID within a given program. This is typically called when loading a promoter's profile page or verifying promoter attributes before performing an action.

## Method and Path

```http
GET /api/programs/:program_id/promoters/:promoter_id
```

## Authentication

<Note>
  A valid **Bearer Token** is required. Include it as `Authorization: Bearer <token>`.
</Note>

## Request

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program that contains the promoter.
</ParamField>

<ParamField path="promoter_id" type="string (uuid)" required>
  Unique identifier of the promoter to retrieve.
</ParamField>

## Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully fetched promoter."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="promoter_id" type="string (uuid)">
      Unique identifier for the promoter.
    </ResponseField>
    <ResponseField name="name" type="string">
      Display name of the promoter.
    </ResponseField>
    <ResponseField name="logo_url" type="string">
      URL of the promoter's logo, if set.
    </ResponseField>
    <ResponseField name="status" type="string">
      Current status of the promoter: `active` | `archived`.
    </ResponseField>
    <ResponseField name="accepted_terms_and_conditions" type="boolean">
      Whether the promoter has accepted the program's terms and conditions.
    </ResponseField>
    <ResponseField name="admin_member_email" type="string">
      Email address of the promoter's admin member, if available.
    </ResponseField>
    <ResponseField name="created_at" type="string (ISO 8601)">
      Timestamp when the promoter was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string (ISO 8601)">
      Timestamp when the promoter was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

```bash
curl -X GET https://your-cliq-instance.com/api/programs/a1b2c3d4-0000-0000-0000-000000000001/promoters/p5e6f7g8-0000-0000-0000-000000000002 \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Promoter fetched successfully. |
| `400 Bad Request` | Invalid UUID format for `program_id` or `promoter_id`. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated member lacks read access to this promoter. |
| `404 Not Found` | No promoter found for the provided IDs. |
