The `contact.created` event is published by Cliq whenever a brand-new contact is created via a referral link in a program. This event gives program owners full visibility into each new contact as they enter the referral funnel, including their profile details and external identifier.

**Event type:** `in.org.quicko.cliq.contact.created`

<Note>
This event is available for **program-level webhooks only**. It is not emitted to promoter-level webhooks. Register your webhook via `POST /programs/:program_id/webhooks` and include `in.org.quicko.cliq.contact.created` in the `events` array to receive it.
</Note>

## Event Schema

<ResponseField name="id" type="string (uuid)" required>
  Unique identifier for this event. Use this field for deduplication.
</ResponseField>

<ResponseField name="time" type="string (ISO 8601)" required>
  The timestamp at which the event was emitted.
</ResponseField>

<ResponseField name="specversion" type="string" required>
  The CloudEvents specification version. Always `"1.0"`.
</ResponseField>

<ResponseField name="datacontenttype" type="string" required>
  The content type of the `data` field. Always `"application/json"`.
</ResponseField>

<ResponseField name="program_id" type="string (uuid)" required>
  The ID of the referral program this contact belongs to.
</ResponseField>

<ResponseField name="promoter_id" type="string (uuid)" required>
  The ID of the promoter whose referral link the contact used when signing up.
</ResponseField>

<ResponseField name="source" type="string" required>
  The originating endpoint that produced the event (e.g. `"urn:POST:/signups"`).
</ResponseField>

<ResponseField name="type" type="string" required>
  The event type identifier. Always `"in.org.quicko.cliq.contact.created"`.
</ResponseField>

<ResponseField name="subject" type="string (uuid)" required>
  The ID of the contact that triggered this event.
</ResponseField>

<ResponseField name="data" type="object" required>
  The full profile details of the newly created contact.

  <Expandable title="data fields">
    <ResponseField name="@entity" type="string" required>
      The entity type identifier. Always `"in.org.quicko.cliq.contact"`.
    </ResponseField>

    <ResponseField name="contact_id" type="string (uuid)" required>
      The unique ID of the created contact.
    </ResponseField>

    <ResponseField name="email" type="string" required>
      The email address of the contact.
    </ResponseField>

    <ResponseField name="first_name" type="string">
      The first name of the contact.
    </ResponseField>

    <ResponseField name="last_name" type="string">
      The last name of the contact.
    </ResponseField>

    <ResponseField name="phone" type="string">
      The phone number of the contact.
    </ResponseField>

    <ResponseField name="external_id" type="string">
      An external identifier supplied by your system when the signup or purchase was posted.
    </ResponseField>

    <ResponseField name="created_at" type="string (ISO 8601)" required>
      The timestamp when the contact record was created.
    </ResponseField>

    <ResponseField name="updated_at" type="string (ISO 8601)" required>
      The timestamp when the contact record was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>
