---
title: "commission.created — Commission Earned Event Reference"
sidebarTitle: "commission.created"
description: "Fired when a promoter earns a commission after a signup or purchase conversion. Payload includes amount, revenue, conversion type, and promoter details."
---

The `commission.created` event is published by Cliq whenever a commission is generated for a promoter following a successful conversion — either a signup or a purchase via a referral link. It is delivered to every webhook — both program-level and promoter-level — that is subscribed to this event type.

**Event type:** `in.org.quicko.cliq.commission.created`

## Event Schema

<ResponseField name="id" type="string (uuid)" required>
  Unique identifier for this event. Use this field for deduplication.
</ResponseField>

<ResponseField name="time" type="string (ISO 8601)" required>
  The timestamp at which the event was emitted.
</ResponseField>

<ResponseField name="specversion" type="string" required>
  The CloudEvents specification version. Always `"1.0"`.
</ResponseField>

<ResponseField name="datacontenttype" type="string" required>
  The content type of the `data` field. Always `"application/json"`.
</ResponseField>

<ResponseField name="program_id" type="string (uuid)" required>
  The ID of the referral program this commission belongs to.
</ResponseField>

<ResponseField name="promoter_id" type="string (uuid)" required>
  The ID of the promoter who earned the commission.
</ResponseField>

<ResponseField name="source" type="string" required>
  The originating endpoint that produced the event (e.g. `"urn:in.org.quicko.cliq"`).
</ResponseField>

<ResponseField name="type" type="string" required>
  The event type identifier. Always `"in.org.quicko.cliq.commission.created"`.
</ResponseField>

<ResponseField name="subject" type="string (uuid)" required>
  The ID of the commission that triggered this event.
</ResponseField>

<ResponseField name="data" type="object" required>
  The full details of the commission.

  <Expandable title="data fields">
    <ResponseField name="@entity" type="string" required>
      The entity type identifier. Always `"in.org.quicko.cliq.commission"`.
    </ResponseField>

    <ResponseField name="commission_id" type="string (uuid)" required>
      The unique ID of the generated commission record.
    </ResponseField>

    <ResponseField name="contact_id" type="string (uuid)" required>
      The ID of the contact whose action (signup or purchase) triggered the commission.
    </ResponseField>

    <ResponseField name="external_id" type="string">
      An external identifier supplied by your system when the signup or purchase was posted.
    </ResponseField>

    <ResponseField name="conversion_type" type="string" required>
      The type of conversion that triggered this commission. One of `"signup"` or `"purchase"`.
    </ResponseField>

    <ResponseField name="promoter_id" type="string (uuid)" required>
      The ID of the promoter who earned this commission.
    </ResponseField>

    <ResponseField name="link_id" type="string (uuid)" required>
      The ID of the referral link associated with the conversion.
    </ResponseField>

    <ResponseField name="amount" type="number" required>
      The commission amount earned by the promoter.
    </ResponseField>

    <ResponseField name="revenue" type="number" required>
      The revenue generated by the conversion. This is `0` for signup-based commissions.
    </ResponseField>

    <ResponseField name="created_at" type="string (ISO 8601)" required>
      The timestamp when the commission record was created.
    </ResponseField>

    <ResponseField name="updated_at" type="string (ISO 8601)" required>
      The timestamp when the commission record was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>
