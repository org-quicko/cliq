title: "signup.created — Cliq Referral Signup Event Reference"
sidebarTitle: "signup.created"
description: "The signup.created event fires when a contact successfully signs up via a referral link. Includes contact, promoter, link, and UTM tracking data."
---

The `signup.created` event is published by Cliq whenever a contact successfully completes a signup using a referral link. It is delivered to every webhook — both program-level and promoter-level — that is subscribed to this event type.

**Event type:** `in.org.quicko.cliq.signup.created`

## Event Schema

<ResponseField name="id" type="string (uuid)" required>
  Unique identifier for this event. Use this field for deduplication.
</ResponseField>

<ResponseField name="time" type="string (ISO 8601)" required>
  The timestamp at which the event was emitted.
</ResponseField>

<ResponseField name="specversion" type="string" required>
  The CloudEvents specification version. Always `"1.0"`.
</ResponseField>

<ResponseField name="datacontenttype" type="string" required>
  The content type of the `data` field. Always `"application/json"`.
</ResponseField>

<ResponseField name="program_id" type="string (uuid)" required>
  The ID of the referral program this signup belongs to.
</ResponseField>

<ResponseField name="promoter_id" type="string (uuid)" required>
  The ID of the promoter who owns the referral link used for this signup.
</ResponseField>

<ResponseField name="source" type="string" required>
  The originating endpoint that produced the event (e.g. `"urn:POST:/signups"`).
</ResponseField>

<ResponseField name="type" type="string" required>
  The event type identifier. Always `"in.org.quicko.cliq.signup.created"`.
</ResponseField>

<ResponseField name="subject" type="string (uuid)" required>
  The ID of the signup that triggered this event.
</ResponseField>

<ResponseField name="data" type="object" required>
  The full details of the signup action.

  <Expandable title="data fields">
    <ResponseField name="@entity" type="string" required>
      The entity type identifier. Always `"in.org.quicko.cliq.signup"`.
    </ResponseField>

    <ResponseField name="trigger_type" type="string" required>
      The type of trigger that caused this event. Always `"signup"`.
    </ResponseField>

    <ResponseField name="signup_id" type="string (uuid)" required>
      The unique ID of the signup record.
    </ResponseField>

    <ResponseField name="contact_id" type="string (uuid)" required>
      The ID of the contact who signed up.
    </ResponseField>

    <ResponseField name="external_id" type="string">
      An external identifier supplied by your system when the signup was posted.
    </ResponseField>

    <ResponseField name="promoter_id" type="string (uuid)" required>
      The ID of the promoter who owns the referral link used for this signup.
    </ResponseField>

    <ResponseField name="link_id" type="string (uuid)" required>
      The ID of the referral link through which this signup occurred.
    </ResponseField>

    <ResponseField name="created_at" type="string (ISO 8601)" required>
      The timestamp when the signup record was created.
    </ResponseField>

    <ResponseField name="updated_at" type="string (ISO 8601)" required>
      The timestamp when the signup record was last updated.
    </ResponseField>

    <ResponseField name="utm_params" type="object">
      UTM tracking parameters associated with the referral link click. Present only when UTM data was captured.

      <Expandable title="utm_params fields">
        <ResponseField name="utm_id" type="string">
          The UTM ID value.
        </ResponseField>

        <ResponseField name="utm_source" type="string">
          The UTM source value (e.g. `"youtube"`, `"instagram"`).
        </ResponseField>

        <ResponseField name="utm_medium" type="string">
          The UTM medium value (e.g. `"affiliate"`, `"social"`).
        </ResponseField>

        <ResponseField name="utm_campaign" type="string">
          The UTM campaign name.
        </ResponseField>

        <ResponseField name="utm_term" type="string">
          The UTM term value.
        </ResponseField>

        <ResponseField name="utm_content" type="string">
          The UTM content value.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
