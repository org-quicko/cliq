Cliq is a self-hosted affiliate and referral management platform designed for startups that want full control over their data and infrastructure. Built on NestJS and PostgreSQL, it gives your team a complete REST API to create programs, onboard promoters, issue referral links, track conversions, and automatically calculate commissions — all without sending your data to a third-party SaaS vendor.

## Why Cliq?

Most affiliate platforms are closed SaaS products: you hand over your conversion data, pay per event, and accept whatever features the vendor ships. Cliq is different. You deploy it to your own servers with Docker Compose in minutes, own the database, and extend it however you need. It ships with a promoter-facing portal (Angular) and a fully documented REST API, so you can integrate it with your product's existing auth flows or build custom dashboards on top of it.

## Tech Stack

Cliq is built entirely in TypeScript. The API layer is a **NestJS** application backed by **PostgreSQL** (via TypeORM) and **Redis** (for caching and background job queues). The promoter-facing portal is an **Angular** single-page app styled with Angular Material and Tailwind CSS. The entire stack ships as Docker images, so there is nothing to compile or install beyond Docker itself.

<Tip>
  Cliq exposes its API under the `/api` global prefix. All endpoints documented in this site are relative to that prefix, for example `POST /api/users/signup`.
</Tip>
